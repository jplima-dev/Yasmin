MANUAL COMPLETO

Livro do InkDriver

Prepare o tablet, conecte o Workspace e entenda os fluxos de arquivos e backup.

1
Preparar o tabletAplicativos e permissões necessárias
  1. Instale Termux e Termux:Boot pelo F-Droid ou GitHub oficial.
  2. Instale o Tailscale, entre na sua conta e deixe o tablet conectado.
  3. Abra o Termux:Boot pelo ícone uma vez. Isso autoriza o início automático.
  4. Nas configurações do Android, retire a restrição de bateria do Termux, Termux:Boot e Tailscale.
2
Instalar o InkDriverProjeto e dependências
  1. Abra o Termux e atualize os pacotes com pkg update && pkg upgrade -y.
  2. Instale Python e Git com pkg install python git -y.
  3. Clone o repositório do InkDriver para $HOME/drive2 ou copie a pasta do projeto para esse local.
  4. Entre na pasta, crie o ambiente e instale as dependências: python -m venv .venv, . .venv/bin/activate e pip install -r requirements.txt.
3
Gerar a configuração no WorkspaceSem editar o arquivo manualmente
  1. No computador, abra Workspace → Configurações → Integrações → InkDriver.
  2. Preencha pasta de dados, host, porta, usuário e as opções de segurança.
  3. Se ativar login, use uma senha com pelo menos oito caracteres e clique em Gerar segredo.
  4. Preencha R2 e Gmail somente se quiser esses recursos opcionais.
  5. Clique em Baixar .env do InkDriver e mova o arquivo baixado para a raiz de $HOME/drive2 no tablet.
4
Testar e conectar ao WorkspacePrimeiro acesso pela rede privada
  1. No Termux, execute cd $HOME/drive2 && . .venv/bin/activate && python run.py.
  2. No próprio tablet, abra http://127.0.0.1:8000 e confirme que a página carrega.
  3. No Tailscale, copie o IP do tablet no formato 100.x.y.z.
  4. No computador, volte a Workspace → Configurações → InkDriver e informe http://100.x.y.z:8000.
  5. Salve e use Abrir InkDriver. O painel deve abrir na mesma guia.
5
Iniciar automaticamenteInkDriver disponível após reiniciar o tablet
  1. No Termux, crie a pasta de boot: mkdir -p ~/.termux/boot.
  2. Copie o script do projeto: cp scripts/termux-boot-drive2 ~/.termux/boot/20-drive2.
  3. Dê permissão: chmod +x ~/.termux/boot/20-drive2.
  4. Reinicie o tablet, aguarde o Tailscale conectar e teste o endereço salvo no Workspace.
6
Usar arquivos, favoritos e lixeiraRotina diária
  1. Use Arquivos para navegar, criar pastas e enviar conteúdo.
  2. Clique na estrela de um item para vê-lo em Favoritos.
  3. Use Recentes para voltar rapidamente aos últimos itens.
  4. Quando excluir, o arquivo vai primeiro para Lixeira; revise antes da remoção definitiva.
  5. Confira Configurações → Logs recentes quando uma ação não concluir.
7
Ativar backup R2 e arquivo de e-mailRecursos opcionais
  1. Preencha as credenciais R2 no gerador de configuração do Workspace e gere um novo .env.
  2. No InkDriver, abra Backups, adicione somente as pastas que devem ser protegidas e clique em Testar conexão.
  3. Para Gmail, configure o OAuth no Workspace, copie os arquivos de credencial para o tablet e abra Emails.
  4. Teste primeiro sem enviar mensagens à lixeira. Ative a limpeza somente depois de confirmar que as cópias foram validadas.
8
Resolver problemas comunsChecklist de diagnóstico
  • Página não abre: confirme se o processo está rodando e se o Tailscale do tablet está conectado.
  • Endereço mudou: copie novamente o IP Tailscale e atualize o campo do InkDriver no Workspace.
  • Login falha: gere novamente o .env, confira usuário e senha e reinicie o serviço.
  • Não inicia após reiniciar: abra Termux:Boot pelo ícone, confira a permissão do script e as restrições de bateria.
  • Backup falha: teste R2 em Backups e revise os logs em Configurações.
